# Tutorial to create the Latex report in VSCode
## Important Links
Extension needed: https://marketplace.visualstudio.com/items?itemName=James-Yu.latex-workshop <br>
TexLive: https://www.tug.org/texlive/windows.html#install <br>
*Original template(letter): https://www.overleaf.com/latex/templates/ieee-conference-template/grfzhhncsfqn*

## Steps
Install the extension and TexLive (TexLive installation might take some time and space). Login to VSCode with affiliated gitHub account. Clone the repository and you can start working on the report file (.tex).

##
.tex file is the report's source code. <br>
bibliography.bib contains the references which it is needed for the .tex file.
