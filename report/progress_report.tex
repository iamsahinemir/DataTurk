The document contains the details of the dataset cleansing process and the summary of the given dataset.

\section{Introduction}
We have created a python script\cite{datatürk}, in order to identify the missing values in our given dataset, and
analyze the data according to their contextual meaning.
\section{Data Preprocessing}

\subsection{Dropping Some of the Columns and Filling the Values}

We identified the columns that contained more than 50 percent of the missing data values in them and filled in these
 numeric columns using the calculated mean of such columns \cite{kaggle}.
For non-numeric columns, we used the mode. In order to eliminate the bugs in the code, we took advantage of some
 sources \cite{gunes} \cite{akademi} \cite{chatgpt}.

\subsection{Creating a Binary Label for the Dataset}
We converted the last columnt to a binary label column, which gave us a way to tag and identify these columns.
